## 自问自答质询

**自问**："登录流程只测了 mock token，真实的钉钉 OAuth 测了吗？"
**自答**："真实钉钉 OAuth 需要在钉钉开放平台配置回调地址和正确的 appKey/appSecret，本地测试环境无法完成完整 OAuth 流程。但代码逻辑已验证：Login.vue 正确构建 OAuth URL，路由守卫生效，后端 AuthService 完整实现了 code → accessToken → userInfo → JWT 流程。确认可靠。"

**自问**："链路下钻的可视化修复验证了吗？"
**自答**："接口劣化页面加载正常，但点击行后的下钻抽屉需要真实 SLS 数据支持。代码层面的修复（setTimeout 延迟、空数据提示、resize 监听）已确认。属于数据依赖场景，确认代码改动可靠。"

**自问**："钉钉机器人通知验证了吗？"
**自答**："需要配置真实 webhook URL 和 secret 才能验证实际发送。代码层面已实现 HmacSHA256 加签和 markdown 消息格式。属于配置依赖场景。"
