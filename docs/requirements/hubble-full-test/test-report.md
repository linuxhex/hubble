### 发现的问题

**P2 - 业务监控图表在本地测试环境未渲染**
- **现象**：业务监控页面的多维度图表（月度趋势、年度同比、每日订单&电量等）和排名表格未显示
- **根因**：图表数据来自数仓（Doris），本地测试环境未配置数仓连接，接口返回空数据
- **影响**：仅影响本地测试环境，生产环境配置数仓后正常
- **建议**：本地测试环境配置数仓连接，或在无数据时显示"暂无数据"提示
- **定性**：环境配置问题，非代码 bug
