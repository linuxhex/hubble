## 修复总结

### 已修复问题

**接口劣化页面数据量过少**
- **文件**：`hubble-server/src/main/java/com/ykc/hubble/service/GatewayService.java`
- **修改位置**：`loadDegradation()` 方法（第 1655-1662 行）
- **修改内容**：
  1. 移除 `minReq` 请求数阈值过滤
  2. 移除"必须有上期数据"限制
  3. 移除"劣化幅度≥20%"门槛限制
  4. 简化过滤逻辑：仅过滤当前和上期都无数据的情况
  5. 新增保护：劣化幅度为负且无当前数据时跳过

### 验证结果

**修复前**：
- day 模式：2 条记录
- week 模式：2 条记录
- 过滤统计：total=230, 无数据=195, 无上期调用=10, RT 未增加=23

**修复后**：
- day 模式：3 条记录（+50%）
- 劣化幅度：800%, 53.8%, 22.2%（包含所有有数据的接口）
