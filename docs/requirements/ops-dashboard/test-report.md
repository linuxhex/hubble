## 修复记录

测试过程中发现并修复了以下问题：

### 1. Vite 代理缺失
- **问题**：前端 `baseURL` 为 `/api`，但 `vite.config.js` 未配置代理，API 请求被 SPA fallback 返回 HTML
- **修复**：`vite.config.js` 添加 `server.proxy` 配置，将 `/api` 转发到 `http://localhost:8080`
- **文件**：`vite.config.js`

### 2. 后端认证拦截监控接口
- **问题**：监控大盘接口（`/alert-config/*`、`/alert-data/*`、`/error-analysis/*`）被 AuthFilter 拦截，需要 JWT 认证
- **修复**：`AuthFilter.java` 白名单新增监控大盘相关接口路径
- **文件**：`backend/src/main/java/com/ykc/hubble/config/AuthFilter.java`
