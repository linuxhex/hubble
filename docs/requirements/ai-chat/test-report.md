## 深度审计发现

### 1. 趋势大盘：数据造假 ⚠️
```
卡片显示：
- QPS: 596.9 ↑73.88%
- 平均响应时间: 201ms ↓8.29%
- 错误率: 0.05% ↑10.67%
- 吞吐量: 31,566,799 ↑6.42%  ← 标注"吞吐量"但值是总请求数
```
P95 = QPS × 1.5、吞吐量 = QPS / 100，**纯伪造**。

### 2. 秒级图表：吞吐量计算错误 ⚠️
```
吞吐量: 30.10 MB/s  ← totalRequests / 1024 / 1024，把请求数除以1MB当吞吐量
```

### 3. 网关大盘：趋势颜色语义反了 ⚠️
```
错误率 ↑10.67% 显示绿色（up）→ 应该是红色（错误率上升是坏事）
平均响应时间 ↓8.29% 显示红色（down）→ 应该是绿色（RT 下降是好事）
```

```
后端 /gateway/degradation?compareMode=day → 30 条

后端 /gateway/degradation?compareMode=month → 0 条
前端默认选中模式未展示 day 数据（可能默认选了 week）
```

### 6. 流量暴涨：后端全模式返回 0
```
后端 /gateway/traffic-surge?compareMode=day → 0 条
后端 /gateway/traffic-surge?compareMode=week → 0 条
后端 /gateway/traffic-surge?compareMode=month → 0 条
```
根因：loadTrafficSurge 的 day 分支改为"今天截至现在 vs 昨天同一时段"后，当前时段数据可能为空（今天刚开始，请求量少）或上期数据为空。需检查 queryApiStats 是否返回了数据。
