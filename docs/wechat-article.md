# 告别多平台切换！Hubble 一站式监控平台，让运维效率翻倍

---

你是否也经历过这样的场景：

网关报错了，先去 **Kibana** 查日志；发现接口变慢，再切到 **Grafana** 看监控；用户投诉数据异常，又跑到 **ARMS** 追链路；老板问经营数据，还得手动导出 Excel 做报表……

## 🔥 三大核心亮点

### 1. 全链路追踪，从异常到根因只需 3 步

接口劣化页面检测到 P60 耗时异常 → 点击**下钻**查看链路详情 → 点击节点查看**原始日志**。

整个过程不超过 1 分钟。

> 💡 传统方式：Grafana 发现慢接口 → Kibana 搜日志 → ARMS 追链路 → 30 分钟过去了。
>
> Hubble：1 个平台，3 步到位。

### 2. 用户行为可追溯

输入手机号，即可查看用户的完整行为轨迹：访问了哪些页面、调用了哪些接口、响应状态如何、日志级别是什么。

点击**展开链路**，直接看到调用链各节点的服务名、状态、日志数，点击节点可查看原始日志内容。

**用户投诉？30 秒还原现场。**

### 3. 经营分析全景视图

不只是技术监控，还有业务洞察：

- **6 大指标卡**：累计订单量、累计电量、枪总量、充电中枪数、小程序 DAU、广告点击数
- **多维图表**：小时对比、月度趋势、年度同比、收入趋势、枪利用率、充电时段分布
- **排名分析**：区域 Top20、站点 Top20、业务场景拆分

**管理者和技术团队，共用一个平台。**

## 🚀 一键部署，开箱即用

没有复杂的依赖，没有繁琐的配置：

```bash
# 克隆项目
git clone https://github.com/linuxhex/hubble.git

# 一键构建（前端 + 后端打包成一个 JAR）
cd hubble
bash build.sh

# 启动
java -jar hubble-server/target/hubble-1.0.0.jar
```

**一个 JAR 包，零外部依赖，即刻运行。**

内置 H2 内存数据库，配置好阿里云 SLS/ARMS 的 AccessKey 就能开始监控。

## 🏗️ 技术栈

| 层级 | 技术 |
|------|------|
| 前端 | Vue 3 + Vite + Element Plus + ECharts + Pinia |
| 后端 | Spring Boot 3 + MyBatis-Plus + H2 + Caffeine |
| 数据源 | 阿里云 SLS + ARMS + CloudMonitor + DashScope |
| AI | 通义千问（qwen-turbo）+ Milvus 向量数据库 |
| 认证 | JWT + 钉钉 OAuth |
| 部署 | 单 JAR / Docker |

深度集成 **12+ 阿里云服务**：SLS 日志、ARMS 链路追踪、CloudMonitor 中间件监控、RDS、PolarDB、Redis、RocketMQ、Kafka、Elasticsearch、Lindorm、OSS、DashScope AI。
